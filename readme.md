# AI-Based Youth Tobacco Risk Early Warning System

This project uses the Global Youth Tobacco Survey (GYTS-4) dataset from data.gov.in
to identify high-risk regions for youth tobacco usage in India.

## Features
- State-wise tobacco risk scoring
- Rural vs Urban comparison
- Interactive Streamlit dashboard
- Government dataset (IndiaAI)

## Tech Stack
- Python
- Pandas, Matplotlib, Seaborn
- Streamlit

## Dataset
Source: https://data.gov.in

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
